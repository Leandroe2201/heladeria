HELADERÍA LOS NIETOS · ACTUALIZACIÓN V25

Instalación:
1. Cerrá el sistema de escritorio y el servidor Web.
2. Descomprimí este ZIP directamente sobre la carpeta actual del sistema, donde está main.py.
3. Aceptá reemplazar los archivos.
4. Volvé a iniciar el sistema.

IMPORTANTE:
- Este paquete NO contiene data/heladeria.db.
- No borra clientes, pedidos, ventas ni credenciales al instalarlo.
- La nueva función “Limpiar base de datos” se ejecuta SOLO si la usás manualmente desde Configuración y confirmás dos veces.
- Esa limpieza crea un backup y conserva usuarios/PIN, configuración y todas las credenciales de Mercado Pago.
